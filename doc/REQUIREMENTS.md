# 算法题编程智能体：需求说明

## 项目目标

本项目面向 LeetCode 等算法编程题，设计并实现一个编程智能体（coding agent）。用户使用自然语言输入一道编程题，智能体通过与大语言模型交互，完成题目分析、代码编写、测试和结果评审，最后输出可运行的题解代码。

项目重点是让智能体能够根据执行结果持续工作，而不是只调用一次模型生成代码。

## 使用流程

1. 用户输入算法题目和编程语言。
2. 智能体分析题意，规划解题步骤。
3. 智能体在本地创建或修改代码文件。
4. 智能体根据题目生成测试文件，其中明确每个测试输入对应的期望输出，并执行测试命令。
5. 如果测试失败，智能体根据错误信息修改代码并重新测试。
6. 本地测试通过后，智能体对代码进行评审。
7. 系统输出最终代码、测试结果和评审意见。

整体流程如下：

```text
自然语言题目
    -> 分析与规划
    -> 编写代码
    -> 生成测试并执行
    -> 根据结果修改
    -> 代码评审
    -> 输出最终结果
```

## 核心需求

### 1. 模型交互

系统能够向大语言模型发送题目、历史对话和工具信息，并接收模型的文字回复或工具调用。

### 2. 本地工具

智能体能够使用本地工具完成编程任务，至少包括：

- 读取文件；
- 写入或修改文件；
- 执行测试或其他命令。

### 3. 自动迭代

系统能够保存每轮对话和执行结果，并将测试输出反馈给模型，使模型可以继续分析和修改代码或测试用例，直到本地测试通过并主动结束。

### 4. 代码评审

代码生成和测试完成后，系统能够给出算法正确性、复杂度、边界情况和代码质量方面的评审意见。

### 5. 结果展示

系统最终展示并保存：

- 题解源代码；
- 测试结果；
- 代码评审意见；
- 智能体的运行过程。

## 预期效果

输入一道例如“实现最长不重复子串”的算法题后，智能体能够自主完成以下工作：

1. 理解题目和约束条件；
2. 编写题解代码；
3. 根据题目编写包含输入和期望输出的样例、边界测试，并运行测试；
4. 根据测试错误继续修改代码；
5. 在本地测试通过后输出代码和评审结果。

最终项目应体现一个完整的“模型分析、工具执行、结果反馈、持续迭代”的编程智能体流程。
